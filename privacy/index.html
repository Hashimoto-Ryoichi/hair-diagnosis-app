プライバシーポリシー

このサイトについて

このサイト（hashimoto-ryoichi.com）は、東京・原宿のフリーランス美容師 橋元リョウイチが運営しています。サイトの使いやすさを上げるために集める情報と、その扱い方を以下にまとめます。

アクセス解析について

このサイトでは、次の2つのアクセス解析ツールを使っています。集めた情報は、サイトの見やすさ・使いやすさを改善するためだけに使います。

  • Cloudflare Web Analytics（Cloudflare, Inc.）：ページが表示された回数や、どのページから来たかを集計します。Cookieは使いません。
  • Microsoft Clarity（Microsoft Corporation）：ページ上でのクリック・タップ・スクロールなどの操作や、ページがどう表示されたかを記録し、ヒートマップや操作の再生として分析します。記録にはCookieなどの技術を使います。入力欄の内容など、機密性の高い情報は自動的に隠された状態で記録されます。

Microsoft Clarityでは、Microsoft社がこのサイトの訪問者の情報を取得・受信し、同社のサービス（Microsoft Advertisingを含みます）の提供のために利用することがあります。Microsoft社による情報の取り扱いは、Microsoft プライバシー ステートメントをご覧ください。

記録されたくない場合は、ブラウザの設定でCookieを無効にするか、こちらのページからMicrosoftを選んで、オプトアウト（記録の停止）ができます。

アフィリエイトについて

シャンプー診断「Hair Identity」（/shampoo/）では、商品の紹介にアフィリエイトリンクを使っています。リンクからお買い物をされた場合、販売元のサイトがCookieなどを使って紹介元を記録し、このサイトに紹介料が支払われることがあります。

Amazonのアソシエイトとして、Hair Identity（橋元リョウイチ）は適格販売により収入を得ています。このサイトは楽天アフィリエイトプログラムにも参加しており、掲載リンクから商品を購入された場合、紹介料を受け取る場合があります。

個人情報の取り扱い

このサイトには入力フォームがなく、お名前やご連絡先などの個人情報をサイト上で集めることはありません。ご予約・ご相談はLINE（LINEヤフー株式会社のサービス）で承っており、いただいた内容は、ご予約・ご相談への対応のためだけに使います。
